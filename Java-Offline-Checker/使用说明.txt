EIE3320 离线 Java 检查器 2.1

2.1 的变化
- 修复会改坏正确代码的自动补分号（文本块 """、以 - 开头的跨行表达式）。
- 缺分号识别覆盖字段、this.x = y、泛型声明、方法调用、赋值、break、do-while、import；else if / while 缺圆括号可自动修正。
- 名为 in 的 Scanner、List.of、Thread.sleep、增强 for 循环变量不再误报。
- 本机编译只在内存中进行，不再生成 .checker-work 或 .class 文件。
- 回车自动缩进；选中多行按 Tab / Shift+Tab 缩进；可用 Ctrl+Z 撤销。检查一次后，继续编辑会自动重新检查。
- 导入 GBK 编码的 .java 自动识别，下载时保存为 UTF-8。

2.0 的重点
- JDK 已连接时，生成前先编译原代码。原代码能编译，则保留原代码。
- 默认仅生成语法/明确类型错误的修正草稿；加打印、字符改字符串、猜变量或构造器名称等建议默认不勾选。
- “逐项建议”可以手动选择这些修改；它们可能改变输出、名称或方法签名，需核对题目。
- 缺 return 会解释原因，不自动猜 0 或空字符串；缺常用 import 可由 JDK 的明确诊断触发修正。
- 支持恢复本机浏览器草稿与清除草稿；受浏览器权限和端口影响，请及时下载硬盘文件。
- 文件名与 public 类名不同时，可点“按 public 类名改文件名”，保留给定类名与方法头。

一、直接打开（不需要 Java，不需要联网）
双击 index.html → 粘贴代码或导入 .java → 检查常见错误 → 生成语法草稿 / 逐项建议 → 应用 → 下载当前文件。
规则检查可能漏报或误报，不是完整编译器。它只提供限定模式的修正，不是离线大语言模型。
“生成语法草稿”会对当前文件分轮应用明确修正，展示完整修改前后代码和原因。
已连接 JDK 时会自动验证修正版；未通过时明确标为草稿，可以继续手改。
可直接下载修正版草稿，也可应用到编辑器再继续编辑；是否编译通过请看验证结果。
补全是轻量名称/模板补全：输入两个字母或按补全按钮，↑↓ 选择，Enter/Tab 接受，Esc 关闭。
sout 补出打印语句，psvm 补出 main。它不等同于 VS Code 的完整 Java 语言服务，也不会生成任意算法。

二、真实编译（需要本机完整 JDK 17 或更高版本）
1. 解压整个文件夹到本机硬盘，路径可有中文和空格。
2. 双击 CHECK_WITH_JDK.cmd，保持命令窗口打开。
3. 启动器会尝试自动打开浏览器；若未打开，将窗口的 Local 地址复制到浏览器地址栏，不要建成 txt 文件。
4. 独立程序：选中对应文件，按“编译当前文件”，不受其他旧文件错误影响。
   相互依赖的多个类：导入同一道题全部源文件，按“编译全部”。
   导入文件会加入列表，不会清除已有文件；检查结果会显示编译范围及实际出错文件名。
5. 修改完成后下载每个文件；在原 IDE 里运行并核对样例。
6. 用 Ctrl+C 关闭命令窗口中的服务器。
127.0.0.1 只指向这台电脑，无需互联网。默认端口 8765，被占用时依次尝试 8766 至 8775。
如果网页直接从 file:// 打开，真实编译按钮禁用是正常的，请使用启动窗口给出的 http://127.0.0.1 地址。
如果系统选中了旧版 Java，可设置 JAVA_HOME 为 JDK 17+ 文件夹后重新启动。

三、范围
支持最多 20 个独立命名的 .java 文件、JDK 标准库、UTF-8 源码；语言级别固定 Java 17。
同一道题内的 public 类名须与文件名一致；不要把不同题目的同名 Main/Item 类混在一起。
单文件最多 100,000 字符，请求最多 600,000 字节。只支持简单文件名，不支持项目目录结构或额外 JAR。
方法片段可做规则检查；真实编译请提供完整的类、import 和依赖文件。
不执行你的程序，不运行 main，关闭注解处理。编译通过后仍须人工检查逻辑、输出、边界条件。
不是自动补全任意逻辑错误的 AI。对于不确定的修改，只给出建议。
代码在页面内编辑，并尝试保存到当前浏览器的本地草稿；需点“恢复草稿”才能重新载入。
浏览器隐私模式、清理缓存、地址或端口改变可能影响恢复；务必下载 .java，不会自动改原硬盘文件，不会上传外部服务。
编译只在内存中进行，不在本文件夹生成临时文件或 .class 文件；2.0 留下的 .checker-work 文件夹可以手动删除。
导入的 .java 若不是 UTF-8（例如 GBK），会自动按 GBK 读取；下载的文件统一为 UTF-8。
JDK 及系统权限由使用电脑决定。纯网页模式本身没有外部依赖。

四、文件
index.html：完整网页及所有 CSS/JS，离线可直接打开。
OfflineJavaChecker.java：本地编译服务源码，可审阅。
CHECK_WITH_JDK.cmd：Windows 启动器，无安装或下载步骤。
examples：错误示例及其修正版本，分别打开，不要一起导入同名 Main 类。
verification.json：交付前实际验证结果。
tests/run_tests.mjs：维护用回归测试（node tests/run_tests.mjs --jdk），学生使用时不需要。
