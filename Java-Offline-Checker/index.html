      如何确保离线可用？
      1. 双击 index.html 即可做浏览器规则检查和生成语法草稿；不需要 Java 或互联网。
      2. 真实编译需运行 CHECK_WITH_JDK.cmd，保持窗口打开并使用它显示的本机地址。断开 Wi-Fi 或网线仍能使用。
      3. 一道题的依赖类一起导入，生成前范围选“全部文件”；独立程序选“当前文件”。若需要第三方 JAR 或项目目录结构，请使用 IDE。
      4. 草稿尽可能保存至本机浏览器，可显式恢复和清除；隐私模式、浏览器限制或更换端口时可能无法恢复，请及时下载每个 .java。
      只访问本机，不运行 main，不加载注解处理器。编译语言级别为 Java 17。
      

      能检查和修正什么？
      重点覆盖你练习中出现过的问题：printIn / println、nuul / null、缺少 if 条件括号、部分缺失分号、数组与 String 的 length 区别、集合的 size、循环变量和括号配对等。确定替换位置后才能提供修正预览；不确定的问题只解释，不擅自改。
      JDK 编译会进一步发现找不到名称、返回类型错误、缺少 return、构造器或继承签名不匹配等，并附中文排查方向。循环范围、提前 return、对象共享、输出格式等仍需按题目测试。
