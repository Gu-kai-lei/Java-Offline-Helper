在 BlueJ 里运行生成的代码

方法 A：下载 BlueJ 项目 ZIP

  1. 点「下载 BlueJ 项目 ZIP」，在下载文件夹里右键 ZIP → 全部解压缩，把文件夹放到本机硬盘（例如 D:\Test2）。
  2. BlueJ：Project → Open Project → 选解压出的文件夹 → 点 Compile。
  3. 右键主类 → Run JavaFX Application。

方法 B：复制粘贴

  1. BlueJ：Project → New Project（或打开题目给的项目）。
  2. New Class → 名字和代码里 public class 后面的名字完全一样（区分大小写）。
  3. 双击打开 → Ctrl+A 全选 → 粘贴替换 → Compile。多个文件就对每个文件重复一次。
  4. 题目已经给了某个类（例如 Shape.java）时，不要再新建同名类，生成器选「只输出主程序」。

读写的 .txt 文件位于 BlueJ 项目文件夹。System.out 的输出在 View → Show Terminal。
